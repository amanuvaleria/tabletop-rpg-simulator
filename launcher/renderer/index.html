Quem é o Mestre

Sem Mestre fixo, quem entra primeiro na sala vira Mestre. Com Mestre fixo, a pessoa que bater com o nome (e a senha, se você definir) ou com o IP configurado assume o cargo; ninguém mais herda.

Com senha, a tela de entrada do jogo passa a mostrar o campo “Senha de Mestre” para todos; só quem a digitar corretamente vira Mestre. Com IP, quem entrar a partir daquele computador já vira Mestre direto, sem precisar de senha. Atenção: o IP pode ser compartilhado (mesma rede/NAT) e, atrás de túnel ou proxy, o servidor pode ver o IP do proxy; para esses casos, prefira nickname + senha. Pode usar os dois: qualquer um dos critérios que bater já promove.
